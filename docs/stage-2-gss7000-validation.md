# 阶段二 GSS7000 独立验收

依据 SimREPLAYplus v10.02.00 远控接口设计，现场 v6_00_02 兼容性待实测。无需手工填写指令。正式测试引擎暂不切换。

## 准备
- 确认屏蔽箱、RF 接线及场景安全；关闭原厂独占远控客户端。
- 使用现场可达的远控地址或 TCP 转发地址，端口 15650；LF 为待验证默认结束符。
- 更新当前开发分支，运行 uv run --locked python -m desktop，打开 GSS7000 调试。
- 填写仪表场景完整路径（仪表文件系统，不是上位机），功率参考 dB 与实际启用的 GPS SVID。
- 每项记录 PASS/FAIL、实际仪表显示、日志；日志 results/gss-debug/commands.log。软件 PASS 仅代表命令响应及指定状态检查成功，RF 和实际功率仍须核验。

| 编号 | 点击操作 | 验收标准 |
|---|---|---|
| P2-01 | 连接 / 状态 | 完整 XML、无错误、状态与仪表一致 |
| P2-02 | 仪表信息 | 返回身份信息；与实机型号版本核对 |
| P2-03 | 当前场景 | 场景名与仪表一致 |
| P2-04 | 加载场景 | 最终状态 2，场景名正确 |
| P2-05 | 启动场景 | 自动设置软件触发并等待状态 5，仪表实际运行 |
| P2-06 | 读取 GPS 参考功率 | 指定启用 SVID 返回有效数值，与仪表显示核对 |
| P2-07 | 设置 GPS 参考功率 | 在批准范围内设置，重新读回并与仪表核对 |
| P2-08 | 设置 GPS 参考功率 | 输入较前值低 1 dB，读回变化；再恢复原值 |
| P2-09 | 停止并复位 | 最终状态 2，仪表停止；核对 RF |
| P2-10 | 重复启动、停止 | 连续三次成功 |
| P2-11 | USB 定位采集 | 场景运行时补验新鲜定位、TTFF、解算卫星数 |
| P2-12 | 断开网络后查询 | 明确失败，不自动重发控制命令 |

功率为参考 dB，不是手机端 dBm；当前设置范围仅 GPS vehicle 1，不能作为全星座绝对功率验收。读取模板 GPS 信号类型须在旧版现场验证。任何失败保留原始响应，不盲目重试；状态不明时在仪表本地确认停止。原始命令区仅供开发排障。

## 版本兼容
默认选择 6.00.02，现场确认 POW_LEV 设置后原厂界面有变化；SIG_LEVEL 不支持，读回按钮禁用，验收 P2-06 标记不适用。P2-07/08 通过原厂界面核对，软件记录仅为收到无错误响应的设置值，不是实际功率。V6 时间查询使用 -,TIME，仍需现场验证立即时间戳。V10.02.00 保留 TIME 和 SIG_LEVEL，待实机验收。版本手动选择并保存，不从硬件型号猜测；模板按版本隔离。任何其他操作保守清除已确认设置值。原始命令仅用于高级诊断。
